# TTP229 单按键控制说明

控制端不再使用滑条，也不区分任何触点的具体位置。TTP229 的 16 个触点中只要有任意
一个或多个触点被判定为按下，就统一作为同一个逻辑按键输入。

实现位置：

- `realize/ttp229/`：两线串行读取和统一按键消抖
- `realize/ui_task/`：短按/长按状态机和设置更新
- `realize/sk9822_task/`：控制目标提示灯效

## 1. 按键与控制目标

统一按键包含全部 16 个原始位：

```cpp
BUTTON_RAW_MASK = 0xFFFF; // pad1..pad16
```

单点、多点、功能键区域和原滑条区域的行为完全相同；逻辑只判断原始状态是否为零，
不再计算触点位置、滑动方向或移动距离。

按下和释放分别需要连续 2 帧、3 帧确认。短按必须在释放时确认，长按不会同时触发短按。

短按按以下顺序循环控制目标：

```text
模式 → 音量 → 网络 → 热点 → 模式
```

| 当前控制目标 | 长按行为 |
|---|---|
| 模式 | 长按 800 ms 后立即切换一次输入模式，继续按住时每 1200 ms 再切换一次 |
| 音量 | 每 100 ms 改变 2；先增加到 100，停 800 ms 后降低到 0 并停止 |
| 网络 | 长按 800 ms 后切换一次连接/断开，继续按住不重复切换 |
| 热点 | 长按 800 ms 后切换一次打开/关闭，继续按住不重复切换 |

每次重新长按音量都会从增加方向开始。模式仍按 `无模式 → SLE → DLNA → 无模式`
循环。网络或热点改变时保留另一个状态位。

## 2. 控制目标灯效

短按切换目标后，SK9822 用浅绿色进度条显示当前目标 1 秒，然后恢复原有灯效。
灯带共映射为 9 个视觉列：

| 控制目标 | 提示灯效 |
|---|---|
| 模式 | 9 列全灭 |
| 音量 | 左侧 3 列浅绿色，即 1/3 |
| 网络 | 左侧 6 列浅绿色，即 2/3 |
| 热点 | 9 列全部浅绿色 |

上电默认目标为模式，也会显示一次 1 秒全灭提示。控制目标提示是覆盖层，不修改亮度、
模式、网络或热点设置。长按实际改变设置后，原有的音量白条、模式波纹、网络/热点滑动
灯效可以覆盖控制目标提示。

## 3. 设置同步与持久化

UI 继续通过统一设置接口修改配置：

- `spi_settings_update_mode()`
- `spi_settings_update_volume()`
- `spi_settings_update_hotspot_network()`

设置变化会标记 NV 待保存，并由控制端通信任务同步到接收端。连续调音量期间不会频繁
写 Flash；最后一次变化 5 秒后才会写入。

## 4. 验证清单

- [ ] pad1..pad16 任意一个触点都产生完全相同的操作
- [ ] 同时按下多个触点仍只算一次按下，不会重复触发
- [ ] 短按只切换一次目标，长按不额外切换目标
- [ ] 四次短按按“音量 → 网络 → 热点 → 模式”回到起点
- [ ] 模式、音量、网络、热点分别显示 0、3、6、9 列浅绿色 1 秒
- [ ] 模式长按首次只切换一次，持续按住时每约 1.2 秒切换一次
- [ ] 音量缓慢增加到 100，停顿后降低到 0 并停止
- [ ] 网络和热点每次长按都只翻转一次
- [ ] 设置变化能同步到接收端并在空闲后保存到 NV
